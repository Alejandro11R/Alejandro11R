## <img src="assets/icons/rocket.svg" width="20" height="20" align="absmiddle" alt=""> Featured projects

- **[MusicX (Cadence)](https://github.com/Alejandro11R/MusicX)**: High-performance, lightweight desktop music launcher and focus engine built with **Rust** and **Tauri v2**. Features Unix domain socket IPC with `mpv`, YouTube stream resolution via `yt-dlp`, real-time audio FX filters (Lo-Fi, Bass Boost, Nightcore), 60 fps synced lyrics engine (LRCLib), and an integrated CLI client (`cadence-cli`).
- **[N_queens](https://github.com/Medina07P/N_queens)**: Metaheuristic AI solution for the classic N-Queens problem using Genetic Algorithms (selection, crossover, mutation, and fitness evaluation) with an interactive UI and REST API.
- **[Tienda Electrónica (Software Architecture)](https://github.com/Alejandro11R/Tienda-Electronica)**: Architectural design and quality evaluation applying the **Quality Attribute Workshop (QAW)** methodology. Prioritized performance efficiency, reliability, maintainability, and security scenarios with layered architecture and SOLID principles.
- **[Verify](https://github.com/Alejandro11R/verify)**: Ultra-fast local Git hook written in **Rust** that intercepts leaked credentials, `.env` files, and API keys during `pre-commit` and `pre-push` in milliseconds before reaching remote repositories.
